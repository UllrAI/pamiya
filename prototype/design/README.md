# Pamiya UI visual source

- `selected-home.png`: the user-approved ImageGen result, generated with the built-in image generation tool. It established the quiet native desktop Agent direction after the user supplied a visual reference.
- `home-prompt.txt`: generation prompt. The supplied third-party reference screenshot is not redistributed in this repository.
- `implemented-home.png` and `implemented-artifact.png`: actual browser captures of the interactive prototype.
- `qa/`: normalized comparison inputs and responsive captures; see [design QA](../design-qa.md).

The home design contains no decorative raster image, custom pictorial logo or avatar. Pamiya is an editable text wordmark; icons come from Phosphor. The selected PNG is a reference, not a raster UI implementation. Product specifications are [English](../../docs/product/en/README.md) and [Chinese](../../docs/product/zh-CN/README.md).
