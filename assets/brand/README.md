# Visual identity / 视觉说明

Pamiya uses a dark panoramic header with a restrained routing network. The network is a conceptual illustration; literal system relationships live in the editable architecture diagrams.

| Asset | Size | Use / 用途 |
|---|---|---|
| [banner.png](banner.png) | 1600 × 400, 4:1 | English and Chinese README header / 双语首页 |
| [social-preview.jpg](social-preview.jpg) | 1280 × 640, 2:1 | GitHub social preview / 仓库分享图 |
| [design.json](design.json) | — | Palette and composition / 配色与构图 |
| [banner-prompt.txt](banner-prompt.txt) | — | Final generation prompt / 最终生成提示词 |

The banner illustration was created with the built-in image generation tool, then exported to the target header and sharing dimensions. The social preview keeps the same artwork with additional background space. Architecture diagrams use Mermaid sources with checked-in SVG/PNG exports.

Dark ink `#101A20`, mint `#87EDD8`, and amber `#FFA957` define the header. Diagrams use a neutral light surface `#F4F7F8`, teal lines `#2D827B`, and dark text. Use sans-serif typography and generous spacing. Keep headers low; do not reuse the taller sharing format as a README banner.

新版视觉使用深色宽幅底图、简洁的路径和节点。配图表达分布式协作概念，具体系统关系由可编辑架构图承担。

Banner 通过内置图像生成工具重绘，再按展示尺寸导出；分享图保留相同内容并增加背景留白。架构图使用 Mermaid 源码，提供 SVG 和 PNG。页面采用无衬线字体与克制配色，保持 banner 低矮，分享图单独适配。
