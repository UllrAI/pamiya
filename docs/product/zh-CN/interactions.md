# 交互规格

[索引](README.md) · [English](../en/interactions.md) · [验收矩阵](prototype-and-acceptance.md)

## 1. 首次使用与发起目标

进入后只见 Pamiya、历史侧栏和“有什么想交给我？”输入区。可以立即写目标，不以欢迎向导、工作区创建或工具配置拦住。生产环境需要登录时仅处理身份；部署者应已准备好默认模型与云端执行能力。

输入框支持多行、附件、拖放与 `@` 引用对话/文件。Enter 发送，Shift+Enter 换行，中文输入法选词的 Enter 不发送。空白禁用发送；仅附件时可用默认“根据这些文件整理方案”，允许随后补充目标。草稿按对话保留；切换回来不丢失。

生产附件区分读取/上传中、可用、失败和不支持；准备未完成的资料不作为已读上下文。文件过大给出可行的替代。当前原型限制单文件 5 MB，文本最多读取 20,000 字符；PDF、图片等只保存信息并明确提示未解析，不上传外部服务。

发出后进入对话。用户消息先出现，Agent 给出简短行动说明，随即开始。要求已经足够时不问“是否开始”。标题自动形成，可在对话设置中修改。网络提交失败保留草稿，生产客户端用稳定请求 ID 防止重复创建。

## 2. 理解、执行与补充方向

活动摘要说明正在做什么，如“正在阅读资料”“正在完善方案”；可展开已经发生的工具活动及来源。不能展示伪造百分比、固定三阶段进度或私有推理全文。普通读取失败由运行时自动恢复；不把每次工具调用变成弹窗。

用户执行中发送补充，默认加入当前目标，在下一个可用边界吸收。UI 回复“收到，这条补充已记下”。如果新要求实质替换目标，生产 Agent 应说明将放弃什么，并给出停止当前工作或下一轮再做；不同时让两个控制循环修改同一现场。原型把所有执行中消息记为本轮补充，不做真实语义判断。

点击历史可以离开，真实云端执行继续；有需要输入的状态时在对应对话提示。默认只在应用内展示结果，不擅自开系统通知、邮件或消息推送。尚未看见的结果不标成已读。

## 3. 只澄清必要信息

受众、目标或关键输入不同会明显改变成果时，问一个具体问题。例如“这份介绍主要给谁看？”同时提供“新用户 / 团队成员 / 投资人”快捷答案和自由输入。收到答案继续同一轮，不重新创建工具意图。

不必把“缺少截止时间”“没有偏好字体”都变成阻塞。可以合理默认、注明假设并开始。暂时不回答可切换对话；结束本轮后保留上下文。

## 4. 按需连接与授权

缺少资源时，直接在对话说明对象与用途：“需要读取演示工作区的资料。”操作提供连接、换资料或结束本轮。连接弹窗显示资源、可访问范围与真实状态；明确点击连接本身就是该范围内的授权，不再加一次通用确认。

生产连接经过相应 OAuth/本地代理流程，凭据不进入消息正文与模型上下文。连接完成后回到同一对话、继续原 Run；失败保留目标与已完成内容。撤销后不再安排依赖该资源的新操作，跟踪在途操作，其他资源与对话不冻结。

桌面/Edge/设备入口在具体目标需要时出现。选择的是工作现场或物理设备，Worker 是实现归属。提示“已连接，摄像头不可用”比单一绿色在线状态更准确。专家 Agent 委托显示目标、进展、成果和实际可用的停止操作；远程超时按任务 ID 查询，不创建第二个专家任务。

## 5. 完成与成果迭代

完成消息给出结论、成果入口和必要限制，避免“工具调用成功”式汇报。点击成果在右侧展开文档；窄屏切到成果全屏。保留对话上下文和输入位置。成果区提供标题、当前版本、编辑、下载与关闭；操作不会把用户带离对话。

编辑进入 Markdown 文本，保存创建新版本，历史版本可查看与下载。取消、切换对话或关闭时有未保存内容，才询问保存/放弃/继续编辑。内容未变不提醒。查看历史不替换当前版本，编辑按钮禁用，并标明正在查看历史。

回到对话要求修改时，更新同一成果的下一版本并保留人工内容。生产环境按版本比较后修改，不能让迟到的执行结果覆盖用户修改。当前原型用追加修订段落模拟语义修改，不声称具有真实编辑智能。

没有文件类成果时，可交付有证据的可读回复；不为每个简短问题强制创建文档。文件类型预览能力不足时仍应给出类型、大小和下载入口，不能空白冒充预览。

## 6. 停止、失败与未知结果

| 状态 | 文案与动作 | 语义 |
|---|---|---|
| 正在推进 | 停止执行；可补充方向 | 继续当前目标 |
| 正在停止 | “已停止安排新操作，正在等待当前操作退出” | 停止请求已记录；不宣称执行已结束 |
| 已停止 | 保留已有内容，可发送新消息 | 必要在途工作已确认退出或转入明确核对 |
| 读取失败 | 说明保留进度；重试读取/结束本轮 | 仅安全读取重试，同一意图增加尝试 |
| 提交结果待核对 | 核对回执；其他对话继续 | 已提交的重要效果不能盲目重复 |
| 需要连接 | 连接、替换资料或结束 | 只阻塞依赖的资源 |
| 需要信息 | 快捷答案或自由输入 | 保存上下文，释放计算 |
| 恢复中/中断 | 拉取权威状态；必要时显式继续 | 不把丢线误报失败，也不虚构后台执行 |

对外发布、提交订单、发送消息等效果发生后，停止无法撤回已完成动作。先查询业务结果；有证据后再显示已完成、未发生或仍未知。无法核对时说明需要人工处理的具体对象，不全局冻结工作。原型提供“演示通知已提交，回执未知”的场景，核对只更新结果，不重复提交。

父 Run 停止时停止派生新任务并跟踪子任务。第三方不支持停止时显示真实限制及后续跟踪；不能用统一“已停止”掩盖远程仍运行。可恢复运行的“继续”与定时安排的“恢复安排”含义分别说明，不承诺任意工具/远程 Agent 的暂停恢复。

## 7. 历史与上下文复用

历史按最近使用排序，搜索覆盖标题与消息，支持重命名与归档。归档是可恢复整理，成功后提供撤销，搜索可包含已归档内容。正在执行或有待核对重要效果的对话先处理状态，不藏到归档里。

引用历史通过 `@` 选择明确对话，输入区显示可移除的资料标签；生产应包含所选版本与范围。用户引用一份对话不等于授权扫描所有历史。长标题省略，查看/编辑时可读完整内容。

## 8. 持续安排与事件触发

从相关对话或更多菜单创建。只填名称、目标、每日/每周、时间、时区；先显示下一次具体发生时间再保存。选择 Asia/Shanghai 与 UTC 是当前原型范围，生产用 IANA 时区处理夏令时，重复/缺失时刻的策略必须明确。

首版错过触发采用跳过，不默认积压补跑。一个安排的上次执行仍在进行时合并到当前待处理窗口，不并发修改同一现场。暂停只禁用未来触发，当前执行继续；停止当前执行到对应对话操作。恢复后从下一个未来时刻开始。

列表显示启停、下一次时间、最近执行入口。原型“模拟触发”创建一次演示对话；不会注册后台任务、发送通知或在页面关闭后运行。用户移除安排可撤销。

事件型规则属于随后接入：选可信来源（例如指定目录新增文件），限定简单条件与目标，显示合并/冷却策略、启停和最近执行。规则版本与事件去重在服务端保存。用户不用配置事件总线、编排图或给每条遥测调用模型。

## 9. 记忆、设置与数据

记忆管理显示内容与来源，支持主动添加、编辑、删除，删除后短时可撤销。先不做自动吸收、向量库面板或记忆分层设置。偏好只影响表达与上下文选择，不改变连接权限。

设置保留少量实际需要的选项与演示数据导出，不放租约、重试轮次、Topic、模型温度等内部参数。生产另需账号、连接撤销和数据管理，但不得把它们填到首页当作“功能齐全”。

原型保存于当前浏览器；存储失败时明确提示未保存，并允许下载成果或导出数据。刷新保留已保存消息与版本；本地模拟执行标记中断，已提交的未知效果仍进入核对。跨浏览器/多标签冲突、云同步和灾难恢复不由原型提供。
