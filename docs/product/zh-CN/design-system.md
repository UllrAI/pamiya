# 视觉与组件

[索引](README.md) · [English](../en/design-system.md) · [已确认首页](../../../prototype/design/selected-home.png)

## 视觉方向

以用户确认的灰阶桌面 Agent 视觉为准：白色主画布、轻灰侧栏、紧凑标题、大面积留白、精致输入区。首页的重点是表达目标。使用文字品牌 Pamiya 与一致的图标，不叠加抽象插画、宣传卡片、重复品牌标题或满屏绿色状态块。

已选图尺寸为 1566 × 1004。它保留配色与布局方向；2026-10-15 用户反馈“字号太大”后，排版按下表收紧，覆盖原图的字号与比例。以相同 CSS 视口、1 倍密度比较修改前后；不把物理像素截图当成必须放大的 CSS 尺寸。界面由真实文字、表单与按钮组成。

| 项目 | 规范 |

| 分隔/输入边框 | `#E5E8EC` / `#DCE0E6` |

| 正文 | 正文/输入 14 px，历史 13 px；长文保持舒适行距 |
| 首页标题 | 桌面 28 px，手机 24 px；不随大屏继续放大 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 px 为主 |
| 圆角 | 输入区约 21 px；按钮/轻列表约 8–11 px |

品牌 banner 保持仓库既有设计；产品 UI 不必沿用深色 banner 作为大背景，也不重新设计 logo。图标按钮有可访问名称，文字按钮只承载一个明确动作。

## 关键组件

**侧栏：** 顶部品牌与收起，随后新对话、工具与连接，下面对话列表与搜索；底部更多。当前对话轻灰选中，标题省略，管理动作在悬停/聚焦时出现。收起后主画布保留展开入口，不能困住用户。

**待处理（本地原型）：** 有内容时在历史前提供文字与按件计数；侧栏收起或手机时在主区顶部保留入口。轻量列表分“需要你处理/有新结果”，条目展示目标简称、具体原因和一个主要动作；不增加首页卡片区、任务表或全局进度。已读与已解决分开，不能只用颜色或自动消失的提示表达。键盘可达、关闭后焦点回入口，打开列表不改变输入草稿。

**输入区：** 可多行文字、可移除上下文标签、附件入口、工具连接入口、发送或停止。文字输入始终是主动作，不强迫先选模式、模型或设备。空输入发送弱化且禁用；执行中停止清晰可达，输入补充后出现发送补充动作。

**消息与活动：** 用户消息轻灰底，Agent 回复以正文为主。活动是轻量可展开行；需要用户时用具体提示与动作，不用红色警报包围每次失败。运行、等待、停止、完成同时有文字，不仅依赖颜色。

**当前工作与新消息（本地规则演示）：** 需要时在活动处以一行说明目标、进展与下一步；消息反馈明确已记下、已应用、仅回答、准备替换或已排在之后。后续请求存在时才显示原文入口与撤回动作，暂存时给出继续/撤回；不新增消息模式切换、工作类型表单、队列管理页或固定流程条。结束后保留结果来源，继续修改回到同一成果。

**成果：** 上方标题与当前版本，次级栏选择版本、编辑和下载；正文保持阅读宽度。全屏只是同一成果的显示方式。编辑与预览有明显区别；历史版本不允许被误当成当前编辑对象。

**弹窗：** 用原生 dialog 保障焦点范围与 Escape 关闭，标题简短。表单每项有标签，错误靠近具体输入；默认按钮聚焦不自动执行。未保存的人工内容才触发丢失提醒；普通连接操作不重复确认。

**反馈：** 成功提示不抢焦点，可关闭；归档、移除安排、删除记忆提供短时撤销。阻塞状态留在对话直到处理，不用几秒后消失的 toast 承载关键错误。

## 响应式

| 宽度 | 布局 |
|---|---|
| 大于 1150 px | 248 px 侧栏，首页输入区最大 760 px；对话默认单列，成果按需并排 |
| 761–1150 px | 固定窄侧栏；成果覆盖主内容，关闭返回对话 |
| 360–760 px | 侧栏抽屉；对话/成果轮流占满主区；输入与关闭操作保持可达 |

动态视口高度适应浏览器工具栏。对话和成果正文各自滚动，输入、成果头部和主要动作不被长内容挤出。长文件名、中文长标题、较大字体与弹窗滚动需要单独检查。首版不做手机设备边框或假的系统状态栏。

## 无障碍与质量门槛

语义化按钮、输入与标签；可见键盘焦点；Tab 可达，弹窗 Escape 退出；输入法不误发送。有效正文和说明满足可读对比，图标不作唯一状态说明。手机关键操作采用约 44 px 命中区域，至少不小于适用的可访问目标尺寸。动效遵循减少动态偏好。

同视口对比字形/字号、间距、灰阶、图标与文案，再检查 390 px 和中等宽度。不能用构建成功代替浏览器检查。原型的[设计 QA](../../../prototype/design-qa.md)记录差异、修复、证据与结论。
